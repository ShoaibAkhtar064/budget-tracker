# Budget Tracker Web Application

## Project Overview

The Budget Tracker Web Application is a responsive web application that helps users manage their personal finances by tracking income and expense transactions. Users can add, view, and delete transactions while monitoring their current balance, total income, and total expenses. Financial data is visualized using charts, and all transaction data is stored in the browser using Local Storage so it remains available after refreshing the page.

This project was developed as a Code:You Web Development Capstone Project to demonstrate skills in HTML, CSS, JavaScript, responsive web design, data management, and front-end development.

* HTML5
* CSS3

* JavaScript (ES6)
* Chart.js

---

## Features Implemented

* Responsive design using Flexbox, CSS Grid, and Media Queries.
* Mobile-friendly and desktop-friendly layout.
* Dashboard displaying:

  * Current Balance
  * Total Income
  * Total Expenses
* Add new income and expense transactions.
* Delete existing transactions.
* Validate user input before saving data.
* Store transaction data using JavaScript arrays and objects.
* Save and retrieve transaction data using Local Storage.
* Automatically calculate Total Income, Total Expenses, and Current Balance.
* Display financial information using summary cards.
* Visualize financial data using Chart.js.
* Expense by Category chart.
* Income vs. Expense chart.

## Installation

1. Clone this repository.

2. Open the project in Visual Studio Code.

3. Install the **Live Server** extension for Visual Studio Code (if it is not already installed).

4. Right-click on `index.html` and select **Open with Live Server**.

5. The application will open in your web browser.
